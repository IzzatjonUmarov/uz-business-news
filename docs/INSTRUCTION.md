# Как мы автоматизировали Telegram-канал @umarovs_news

В этом документе по шагам описано, как в чате с Claude был построен бот. Он сам собирает бизнес-новости Узбекистана с официальных сайтов и публикует их в канал [@umarovs_news](https://t.me/umarovs_news). По этой инструкции работу можно повторить для другого канала.

---

## Итог: что делает бот

- **Источники.** Каждые 15 минут бот проверяет 34 официальных источника: Президента, gov.uz, МИД, министерства, налоговую, статистику, фондовую биржу и 17 банков.
- **Отбор.** Новые новости он оценивает по важности для бизнеса. Проходное отсеивается: поздравления, графики работы, тренинги.
- **Пост.** Для каждой новости бот готовит пост на **двух языках**: на русском и на узбекском латиницей в **новой редакции алфавита** (ş, ç, ö, ğ).
- **Картинка.** К каждому посту прикладывается картинка с **водяным знаком** `@umarovs_news`.
- **Публикация.** В канал уходит **не чаще одного поста в 30 минут**, сначала самые важные. В каждом посте есть ссылка на первоисточник.
- **Где работает.** Бесплатно в **GitHub Actions**, круглосуточно, без компьютера и без чата с Claude.

Код: https://github.com/IzzatjonUmarov/uz-business-news

## Этапы: как это делалось

### 1. Постановка задачи
Запрос: «автоматизировать Telegram-блог с бизнес-новостями Узбекистана из официальных источников со ссылками; мониторить ЦБ, МИД и все банки: их активность и новые продукты».

### 2. Каркас бота (Python)
Claude написал бота из нескольких модулей:

| Файл | Что делает |
|---|---|
| `bot/fetch.py` | скачивает новости: RSS, HTML-страницы, API gov.uz |
| `bot/pipeline.py` | очередь: сбор → подготовка → публикация по одной |
| `bot/importance.py` | оценка важности новости (1–5) |
| `bot/uzbek.py`, `bot/translate.py` | узбекская версия и перевод в новый алфавит |
| `bot/images.py` | картинка и водяной знак |
| `bot/format.py` | оформление поста |
| `bot/telegram.py` | отправка в Telegram |
| `config/sources.yaml` | список источников |

### 3. Проверка источников вживую
- **Что нашлось.** Большинство адресов разделов новостей на сайтах устарели (ошибка 404). Claude проверил каждый сайт и нашёл актуальные разделы.
- **gov.uz.** Министерства переехали на портал gov.uz, а он показывает новости только через JavaScript. Claude нашёл внутренний API портала (`api-portal.gov.uz`) и подключил 13 ведомств через него.
- **Что отключено.** Сайты, которые работают только через JavaScript или закрыты защитой от ботов, отключены с пояснением: Асака, Агробанк, Халк банк, Капиталбанк, Anorbank.
- **Что недоступно.** Сайт ЦБ (cbu.uz) закрыт для зарубежных серверов, поэтому из облака его не прочитать.
- **Проверка в любой момент:** `python -m bot check`.

### 4. Подключение к Telegram
1. Бот создан у @BotFather: `@yengiliklar_bot`.
2. Бот добавлен **администратором** в канал с правом публиковать сообщения.
3. Токен бота хранится только в `.env` (он не попадает в git) и в секретах GitHub.

### 5. Картинки с водяным знаком
- **Есть фото новости** → берётся оно.
- **Сайт отдаёт заглушку** (логотип, «social.png», одна и та же картинка у разных новостей) → бот ищет фото в тексте новости.
- **Фото нет** → бот рисует карточку с заголовком в цветах источника.
- **На любой картинке** ставится плашка `@umarovs_news` в углу и бледный диагональный повтор по всему полю.

### 6. Два языка и новый алфавит
- **Формат:** в одном посте русский текст, ниже узбекский.
- **Алфавит.** Узбекский пишется латиницей по **закону ЗРУ-1184 от 21.10.2026**: sh→ş, ch→ç, oʻ→ö, gʻ→ğ, апостроф ʼ ставится только вместо твёрдого знака.
- **Откуда берётся узбекский текст:**
  1. официальная узбекская версия той же новости (API gov.uz, ссылка `hreflang` на странице, адрес с `/uz/`). Найденное сверяется с русской новостью по числам;
  2. если её нет — перевод: Claude, а без ключа бесплатный Google Translate или MyMemory.
- **Приведение к новому алфавиту.** Любой текст (старая латиница, кириллица, смесь) переводится в новую латиницу. Иностранные названия не трогаются.

### 7. Очередь: один пост в 30 минут
- **Проблема:** после перезапуска бот публиковал всё накопившееся залпом.
- **Решение:** новости складываются в очередь, а в канал уходит максимум один пост раз в 30 минут. Время последнего поста сохраняется, поэтому залпа не бывает и после перезапуска.
- **Устаревание:** новости старше 3 дней из очереди выбрасываются.

### 8. Публикация по важности
Каждая новость получает оценку от 1 до 5, и первыми выходят важные.

| Повышает оценку | Понижает оценку |
|---|---|
| ЦБ, Президент, экономические ведомства | поздравления, праздники |
| решения ЦБ, указы, законы, налоги, таможня | графики работы, техработы |
| инвестиции, свободные экономические зоны, экспорт | конкурсы на должности, вакансии |
| кредитные линии ЕБРР, АБР, облигации, IPO | спорт, конкурсы, фестивали |
| новые банковские продукты, изменения ставок и тарифов | тренинги и семинары без цифр |
| суммы (млн/млрд $), проценты | |

- **Порог.** Новости ниже порога 1.8 не публикуются.
- **С ключом Claude API** оценку делает Claude, а правила остаются запасным вариантом.

### 9. Оформление канала
- Аватарка: вариант A — тёмно-синий фон, буква «U», растущий график, кольцо цветов флага. Файл `assets/avatar/avatar_A.png`.
- Описание канала на двух языках (до 255 символов). Аватарку и описание поставил сам бот.

### 10. Перенос на GitHub (работа 24/7)
- **Почему.** Облачная среда чата засыпает, а вместе с ней останавливался и бот.
- **Шаги:**
  1. Создан публичный репозиторий `uz-business-news`. Публичный — значит GitHub Actions бесплатно и без лимита.
  2. Claude загрузил туда код.
  3. Владелец добавил секрет **`TELEGRAM_BOT_TOKEN`**: *Settings → Secrets and variables → Actions*.
  4. Владелец включил GitHub Actions и запустил бота: *Actions → Run workflow*.
- **Где хранится состояние:** что уже опубликовано, очередь и время последнего поста лежат в ветке `bot-state`.

### 11. Непрерывная цепочка запусков
- **Проблема:** расписание GitHub для нового репозитория так и не начало срабатывать.
- **Решение:**
  - один запуск работает около 5,5 часа: внутри источники проверяются каждые 15 минут, а посты уходят по интервалу;
  - после каждого поста состояние сразу сохраняется на GitHub, поэтому дублей нет;
  - перед завершением запуск сам ставит следующий, и получается непрерывная цепочка;
  - цепочка стартует при обновлении кода или вручную (*Run workflow*), а раз в 3 часа есть запасной запуск по расписанию.

## Управление ботом

| Действие | Где |
|---|---|
| Что делает бот сейчас | **Actions** → последний запуск → шаг «Работа бота» |
| Пауза | Actions → Публикация новостей → «…» → **Disable workflow** |
| Возобновить или перезапустить | **Enable workflow**, затем **Run workflow** |
| Интервал между постами | Settings → Secrets and variables → Actions → **Variables**: `POST_INTERVAL_MINUTES` |
| Порог важности | там же: `MIN_IMPORTANCE_RULES` (по умолчанию 1.8) |
| Подключить Claude | там же, вкладка **Secrets**: `ANTHROPIC_API_KEY` |
| Добавить или убрать источник | файл `config/sources.yaml` |

### Если что-то не так

| Симптом | Решение |
|---|---|
| Во вкладке Actions нет запуска, который идёт | Цепочка прервалась: нажмите **Run workflow** |
| Красный крестик на «Проверить токен» | Проверьте секрет `TELEGRAM_BOT_TOKEN` |
| `chat not found` / `not enough rights` | Бот не админ канала или неверный адрес канала |
| Нет новостей ЦБ и курсов | cbu.uz закрыт для зарубежных серверов. Нужен VPS в Узбекистане |

## Как повторить для другого канала

1. Создайте бота у @BotFather и сделайте его **администратором** нового канала с правом публикации.
2. Откройте https://github.com/IzzatjonUmarov/uz-business-news и нажмите **Fork**.
3. В копии откройте вкладку **Actions** и включите workflows (**I understand…, enable them**).
4. **Settings → Secrets and variables → Actions**:
   - **Secrets:** `TELEGRAM_BOT_TOKEN` — токен бота;
   - **Variables:** `TELEGRAM_CHAT_ID` — `@имя_нового_канала`. Без этой переменной бот будет писать в `@umarovs_news`.
5. **Actions → Публикация новостей → Run workflow.** Первый запуск только запоминает текущие новости, публикации начнутся с новых.
6. При необходимости поменяйте источники в `config/sources.yaml`.

Водяной знак на картинках возьмётся из `TELEGRAM_CHAT_ID`, если адрес начинается с `@`.
