# Бизнес-новости Узбекистана → Telegram

Бот следит за официальными сайтами Узбекистана: госорганы, Центробанк, биржа, агентства по инвестициям и 26 банков. Новые публикации он отправляет в ваш Telegram-канал, и в каждом посте есть ссылка на первоисточник.

```
🆕 Агробанк запустил онлайн-депозит со ставкой 22% годовых

Вклад открывается в мобильном приложении, минимальная сумма — 1 млн сумов,
срок — 13 месяцев, проценты выплачиваются ежемесячно.

🔗 Источник: Агробанк · 28.10.2026
#банки #agrobank #депозиты
```

## Как работает

1. **Очередь и интервал.** Бот проверяет источники каждые 15 минут и складывает новые новости в очередь. В канал уходит **не больше одного поста в 30 минут** (`POST_INTERVAL_MINUTES`): сначала важные, затем свежие. Важность оценивает Claude (если задан ключ) или правила в `bot/importance.py`: вес источника, ключевые темы (решения ЦБ, указы, налоги, инвестиции, кредитные линии МФИ, новые банковские продукты и тарифы), суммы и проценты. Поздравления, графики работы, конкурсы на должности и спорт не публикуются. Новости старше 3 дней из очереди убираются. Время последнего поста сохраняется, поэтому и после перезапуска бот не публикует всё накопившееся залпом. Посмотреть очередь: `python -m bot queue`.
1. **Сбор.** Бот обходит все источники из `config/sources.yaml`. Если у сайта есть RSS, бот читает его. Если нет, он сам находит ссылки на новости в HTML-странице.
2. **Без дублей.** Ссылки, которые уже обработаны, хранятся в `data/state.json`. При первой проверке источника бот только запоминает его текущую ленту, чтобы не выложить в канал весь архив.
3. **Отбор и пересказ (необязательно).** Если задан `ANTHROPIC_API_KEY`, Claude оценивает бизнес-значимость новости от 1 до 5. Протокольные новости, спорт и поздравления отсеиваются. Для остальных Claude пишет короткий пересказ **только по тексту официальной страницы** и выбирает категорию: «Новые продукты», «Денежно-кредитная политика», «Инвестиции», «Внешняя торговля» и т. д. Без ключа бот публикует заголовок и описание со страницы.
4. **Два языка.** Каждый пост выходит на русском и узбекском. Узбекский текст пишется латиницей в новой редакции алфавита (закон ЗРУ-1184 от 21.10.2026: Ş, Ç, Ö, Ğ вместо Sh, Ch, Oʻ, Gʻ; апостроф ʼ). Бот берёт официальную узбекскую версию новости: у gov.uz через API, у остальных сайтов по адресу с `/uz/`. Кириллицу и старую латиницу он приводит к новому алфавиту, иностранные названия не трогает. Ссылку на узбекскую версию бот ищет в коде страницы (`hreflang`, переключатель языка) и по вариантам адреса, а найденный текст сверяет с русским по числам. Если официальной версии нет, текст переведёт Claude (при заданном `ANTHROPIC_API_KEY`), а без ключа — бесплатный машинный перевод (Google Translate, запасной вариант MyMemory). Перевод тоже приводится к новой латинице.
5. **Картинка с водяным знаком.** К каждому посту прикладывается картинка. Бот берёт фото новости, а если сайт отдаёт вместо него заглушку (логотип, баннер для соцсетей), ищет фото в тексте новости. Если фото нет совсем, рисует фирменную карточку с заголовком. На любую картинку ставится водяной знак канала: плашка `@канал` (и логотип, если задан) в правом нижнем углу и бледный диагональный повтор надписи по всему полю.
6. **Курсы ЦБ.** Раз в день бот публикует официальные курсы валют из API cbu.uz.

## Быстрый старт

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Добавьте бота **администратором** в свой канал с правом публиковать сообщения.
3. Настройте и запустите:

```bash
python3 -m venv .venv && . .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

```bash
cp .env.example .env    # впишите TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID и при желании ANTHROPIC_API_KEY
```

```bash
python -m bot check            # проверить, что источники находят новости
```

```bash
python -m bot test-telegram    # тестовое сообщение в канал
```

```bash
python -m bot run --dry-run    # посмотреть посты в консоли, ничего не отправляя
```

```bash
python -m bot run --with-rates # реальный запуск: один проход
```

## Запуск фоновым процессом (без Docker)

```bash
./scripts/start.sh     # запуск в фоне с автоперезапуском, проверка каждые 15 минут
```

```bash
./scripts/stop.sh      # остановка
```

Лог пишется в `data/bot.log`. Пока в `.env` не заданы `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, бот работает в **режиме предпросмотра**: собирает новости по расписанию, но вместо канала складывает посты в `data/preview_posts.txt`. Когда впишете токен, выполните `./scripts/stop.sh && ./scripts/start.sh`, и посты пойдут в канал.

## Постоянная работа

**Вариант A: VPS + Docker (рекомендуется).** Часть узбекских госсайтов (налоговая, таможня, gov.uz) иногда закрыта для зарубежных IP. Надёжнее всего работает сервер в Узбекистане, например у UZINFOCOM, Billing.uz или Ahost, либо в соседнем регионе.

```bash
docker compose up -d --build
```

Бот проверяет источники каждые 15 минут. `config/` и `data/` подключены как тома, поэтому источники можно править без пересборки.

**Вариант B: GitHub Actions (бесплатно для публичного репозитория).** Бот работает непрерывной цепочкой запусков. Каждый запуск длится около 5,5 часа (лимит GitHub — 6 часов): внутри бот проверяет источники каждые 15 минут и публикует не чаще одного поста в 30 минут. Перед завершением запуск сам ставит в очередь следующий. Цепочка стартует, когда в `main` загружают новый код, или вручную: *Actions → Публикация новостей → Run workflow*. Раз в 3 часа есть запасной запуск по расписанию. Состояние (что уже отправлено, очередь, время последнего поста) после каждого поста сохраняется в служебную ветку `bot-state`, поэтому при сбое дублей не будет. Нужен один секрет `TELEGRAM_BOT_TOKEN` в *Settings → Secrets and variables → Actions*. Канал задаётся переменной `TELEGRAM_CHAT_ID`, по умолчанию `@umarovs_news`. Пауза: *Actions → Публикация новостей → «…» → Disable workflow*. Сайт ЦБ закрыт для зарубежных IP, поэтому с серверов GitHub он недоступен.

**Вариант C: cron на любом Linux-сервере.**

```
*/20 * * * * cd /opt/uz-business-news && .venv/bin/python -m bot run --with-rates >> bot.log 2>&1
```

## Настройка источников

Министерства на портале gov.uz (МИД, Минфин, налоговая, энергетики и др.) читаются через API портала (`type: govuz`): добавить новое ведомство можно одной строкой, взяв код из адреса `gov.uz/ru/<код>/...`. Все источники перечислены в `config/sources.yaml`: госорганы, ЦБ, биржа, банки. Чтобы добавить сайт, допишите строку:

```yaml
  - {id: mybank, name: Мой банк, group: bank, url: "https://mybank.uz/ru/news/"}
```

Сайты иногда меняют адреса разделов. Если `check` показывает ✗ или ⚠ (0 новостей):

1. Откройте сайт и найдите актуальную страницу со списком новостей. Поправьте `url`.
2. Если находится мусор вместо новостей, укажите `link_pattern`, то есть regex адреса новости, например `/ru/news/\d+`.
3. В крайнем случае задайте CSS-селекторы:

```yaml
    selectors: {item: ".news-card", title: ".news-card__title", date: ".news-card__date"}
```

Проверка одного источника:

```bash
python -m bot check --id cbu
```

## Параметры (`.env`)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | токен бота |
| `TELEGRAM_CHAT_ID` | — | `@канал` или `-100…` |
| `ANTHROPIC_API_KEY` | пусто | включает отбор и пересказ через Claude |
| `AI_MODEL` | `claude-opus-5-5` | модель. `claude-haiku-5-5` примерно в 40 раз дешевле, и для пересказа новостей её обычно хватает |
| `MIN_IMPORTANCE` | `3` | порог значимости 1–5 при оценке Claude. Поставьте `4`, чтобы публиковать только крупные новости |
| `MIN_IMPORTANCE_RULES` | `1.8` | порог значимости 1–5 при оценке по правилам (без ключа Claude) |
| `POST_INTERVAL_MINUTES` | `30` | не чаще одного поста в N минут; остальные новости ждут в очереди |
| `MAX_QUEUE` | `100` | максимум новостей в очереди (лишние — наименее важные и старые — отбрасываются) |
| `MAX_AGE_DAYS` | `3` | не публиковать новости старше N дней |
| `UZBEK_ENABLED` | `true` | узбекская версия (новая латиница) в каждом посте |
| `IMAGES_ENABLED` | `true` | прикладывать картинку к каждому посту |
| `WATERMARK_TEXT` | `@канал` из `TELEGRAM_CHAT_ID` | надпись водяного знака |
| `WATERMARK_LOGO` | пусто | PNG-логотип канала для водяного знака, например `assets/logo.png` |
| `WATERMARK_OPACITY` | `0.85` | непрозрачность плашки в углу |
| `WATERMARK_TILED` | `true` | бледный повтор надписи по всей картинке |
